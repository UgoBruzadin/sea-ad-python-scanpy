# SEA-AD single-nucleus multiome, taught with scanpy

A small, progressive series of Jupyter notebooks that teach single-nucleus
genomics data analysis hands-on, in Python, using `scanpy`. This is a
**learning curriculum**, not a polished portfolio piece — each notebook
teaches a concept in markdown, works a real example against real data, and
ends with homework for you to attempt yourself before checking the
`solutions/` folder.

## Assumed background

Solid Python and general ML background (numpy/pandas/sklearn-style
workflows) — but **new to single-cell/single-nucleus genomics specifically**.
Every notebook explains the domain concepts as they come up (UMI counts,
barcodes, doublets, HVGs, what a UMAP/Leiden cluster means, what a marker
gene is, what chromatin accessibility means, etc.) — that's the whole point
of this series. Basic Python syntax is not re-explained.

Each notebook defines its data paths as constants near the top (`DATA_DIR`,
`RNA_DIR`, `ATAC_DIR`, etc.) — edit those if your local paths differ.

These `.h5ad` files are genuine AnnData-native files; `scanpy`/`anndata`
reads them directly with `sc.read_h5ad()` — no custom parsing needed (unlike
the R side of this project, which had to write a from-scratch h5ad reader,
since R has no native AnnData support).

**Important file-structure note:** each RNA `.h5ad`'s `.obs` has a `method`
column — only rows where `method == "10xMulti"` have a matching nucleus in
the ATAC file (the RNA file also contains RNA-only nuclei, profiled with
`10Xv3.1`, that aren't part of the paired multiome). The ATAC files in this
dataset are already restricted to the multiome-paired subset. `.obs` also
carries SEA-AD's own reference cell-type labels (`Class`/`Subclass`/
`Supertype`) — genuine ground truth used in notebook 03 to validate our own
clustering-based annotation.

## Glossary

- **UMI (Unique Molecular Identifier)** — a random short DNA tag attached to
  each individual mRNA molecule before PCR amplification, so that multiple
  PCR copies of the same original molecule can be collapsed ("deduplicated")
  into a single count. UMI counts are the currency of single-cell/nucleus
  count matrices.
- **Barcode** — a DNA tag unique to a single droplet/nucleus, used to assign
  each sequencing read back to the nucleus it came from.
- **Doublet / multiplet** — a single barcode that captured two (or more)
  nuclei instead of one, producing a "hybrid" transcriptome that can distort
  clustering if not filtered out.
- **HVG (highly variable gene)** — a gene whose expression varies more than
  expected given its mean expression level across the dataset; HVGs are
  selected as the feature set for PCA/clustering because they carry most of
  the biologically meaningful signal.
- **PCA (Principal Component Analysis)** — standard linear dimensionality
  reduction, used here to compress thousands of HVGs into tens of components
  that capture most of the meaningful variance before clustering.
- **Batch effect** — systematic, non-biological variation between samples
  (e.g. donors, sequencing runs) that can distort analysis if not corrected;
  see notebook 02 for a direct visual demonstration.
- **Integration (e.g. Harmony)** — a computational correction applied to an
  embedding (like PCA) to remove batch effects while preserving genuine
  biological structure, so that samples/donors mix appropriately.
- **UMAP (Uniform Manifold Approximation and Projection)** — a nonlinear 2D
  embedding used for *visualizing* high-dimensional single-cell data.
  Preserves local neighborhood structure well; distances between far-apart
  clusters are not quantitatively meaningful. Clustering itself is done in
  PCA space, not on the UMAP coordinates.
- **Leiden clustering** — a graph-based community-detection algorithm used
  to partition a k-nearest-neighbor graph of cells/nuclei into clusters; the
  standard clustering approach in single-cell analysis.
- **Marker gene** — a gene known, from prior biology, to be characteristic
  of a specific cell type; used to translate an unsupervised cluster into a
  named cell type.
- **Differential expression (DE)** — statistical comparison of gene
  expression between groups (e.g. clusters, or disease-severity groups),
  used both for marker discovery (notebook 03) and for a biological
  question of interest (notebook 04).
- **ADNC (Overall AD neuropathological Change)** — a standardized ordinal
  staging of Alzheimer's neuropathology severity (Not AD < Low <
  Intermediate < High), combining amyloid plaque burden, tau tangle spread,
  and neuritic plaque density, assigned by direct postmortem examination.
- **Braak stage** — a specific staging system (0-VI) for the anatomical
  spread of tau neurofibrillary tangles through the brain, one of the inputs
  to ADNC.
- **Peak (ATAC)** — a genomic interval of unusually high sequencing-fragment
  density, indicating a region of open/accessible chromatin, likely to be a
  gene promoter or enhancer. The feature unit of ATAC data, analogous to a
  gene in RNA data.
- **Pseudobulk** — summing/aggregating single-cell counts up to one profile
  per biological replicate (e.g. per donor) before statistical testing, to
  respect that cells from the same donor aren't independent samples; see
  notebook 04.

## Relationship to the companion R project

`~/Documents/GitHub/sea-ad-multiome-cortex/` is a separate, more thorough
Seurat/Signac pipeline built on the same underlying data. This repo is a
different tool (Python/scanpy) for a different purpose (a teaching
curriculum for someone new to the data type, not a polished deliverable) —
it deliberately keeps steps simpler where the R project goes further (e.g.
notebook 05's light ATAC intro vs. the R project's full LSI/WNN multiome
integration).
